## 5. Threat model delta (also in `security.md` v0.2)

- New actors: the *agent itself* (prompt-injected or mistaken) as a source of repository tampering; the *developer shell environment* as a source of configuration (`BASE_URL`, `SERVER_ADDRESS`, datasource) that can redirect tests or expose the app.
- New trust boundary: *orchestrator session credentials ↔ implementer agents*.
- New STRIDE rows: tampering of guards (hooks, agent definitions, ignore rules); information disclosure through container-level errors and logs; denial of service of the single DB connection by slow requests.
- Out of scope, to be recorded: same-user local malware; attackers with root; physical access; browser zero-days. In scope but accepted: plain HTTP on loopback (R-07).

### Tested hook replacements (CA-15)
Both were run in the scratch repository: they reject the `#`-line message, "Co authored by", "Generated  with", Cursor, a zero-width-split name; accept ordinary messages and Git's editor template; the pre-push version rejected the force-push-over-unknown-sha case, the annotated tag message and the AI-identity commit, and accepted a clean push.
```bash
# .githooks/commit-msg
#!/usr/bin/env bash
msg_file="$1"
pattern='(^|[^[:alnum:]_])(claude|anthropic|openai|chatgpt|gemini|copilot|cursor|codex|devin|windsurf|llm)([^[:alnum:]_]|$)|co[- ]?authored[- ]?by|generated +(with|by)|(^|[^[:alnum:]_])gpt-?[0-9]|ai[- ]+(generated|assisted|agent)|claude\.ai|session_[0-9a-z]{8,}'
# Only Git's own editor template is skipped; '#' lines typed by the author are scanned.
body=$(sed '/^# Please enter the commit message/,$d' "$msg_file" | LC_ALL=C tr -d '\200-\377')
# Repository's own names are not attribution (decision S-4): sed -E 's#\.claude/##g; s#CLAUDE\.md##g'
if printf '%s\n' "$body" | grep -qiE "$pattern"; then echo "commit-msg: rejected (AI attribution pattern)" >&2; exit 1; fi
```

```bash
# .githooks/pre-push
#!/usr/bin/env bash
remote="$1"
pattern='(^|[^[:alnum:]_])(claude|anthropic|openai|chatgpt|gemini|copilot|cursor|codex|devin|windsurf|llm)([^[:alnum:]_]|$)|noreply@anthropic|co[- ]?authored[- ]?by|generated +(with|by)|(^|[^[:alnum:]_])gpt-?[0-9]|ai[- ]+(generated|assisted|agent)|claude\.ai|session_[0-9a-z]{8,}'
zero=0000000000000000000000000000000000000000; fail=0
[ -n "$(git config user.name)" ] && [ -n "$(git config user.email)" ] || { echo "pre-push: identity not configured" >&2; fail=1; }
scan() { LC_ALL=C tr -d '\200-\377' | grep -qiE "$pattern"; }
while read -r lref lsha rref rsha; do
  [ "$lsha" = "$zero" ] && continue
  echo "$rref" | scan && { echo "pre-push: ref name '$rref'" >&2; fail=1; }
  commits=$(git rev-list "$lsha" --not --remotes="$remote" 2>/dev/null) || { echo "pre-push: cannot enumerate commits" >&2; fail=1; continue; }
  for c in $commits; do
    git show -s --format='%an <%ae>%n%cn <%ce>%n%B' "$c" | scan && { echo "pre-push: commit $c reveals an AI tool" >&2; fail=1; }
  done
  if [ "$(git cat-file -t "$lsha" 2>/dev/null)" = tag ]; then
    git cat-file -p "$lsha" | scan && { echo "pre-push: tag object reveals an AI tool" >&2; fail=1; }
  fi
done
exit $fail
```
Note: removing non-ASCII bytes before matching also blocks legitimate non-English text only if it contains the patterns; it does not reject non-ASCII messages.
